# Política de Segurança

## Reportar Vulnerabilidades

Se você encontrar uma vulnerabilidade de segurança, por favor reporte de forma responsável.

**NÃO** abra issues públicas para vulnerabilidades de segurança.

## Como Reportar

Envie um email para [seu-email@exemplo.com] com:

1. Descrição da vulnerabilidade
2. Passos para reproduzir
3. Impacto potencial
4. Sugestão de correção (se possível)

## Escopo

- Aplicações web (Flask)
- API endpoints
- Integração com Ollama

## Fora do Escopo

- Vulnerabilidades em dependências de terceiros
- Ataques de negação de serviço
- Problemas de configuração do servidor

## Resposta

- Confirmaremos o recebimento em até 48 horas
- Forneceremos um plano de correção em até 7 dias
- Creditaremos o reporter (se desejado)
